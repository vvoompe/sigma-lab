# Математичне ядро Z1 - issue #5

Код: `src/Lab.Application/Statistics/`. Усі методи чисті: без БД, HTTP, конфігурації та випадкових даних. Це розрахункова частина Z1, не API Z2. Інтеграцію із серіями, DTO та контролерами виконуємо після погодження моделі.

## Контракти

```csharp
var statistics = SeriesStatistics.Calculate(new double[] { 1, 2, 3, 4, 5 }, "м");
var interval = SeriesStatistics.ConfidenceInterval(new double[] { 1, 2, 3, 4, 5 }, "м", 0.95);
var outliers = MeasurementAnalysis.FindOutliers(values, "м");
var comparison = MeasurementAnalysis.CompareToReference(statistics.Mean, "м", 3, "м", 0.5);
var line = LinearRegression.Fit(new double[] { 1, 2, 3 }, new double[] { 3, 5, 7 }, "с", "м");
var predicted = line.Predict(4);
```

Приклад `values` - фактична однорідна серія, яку надає викликач. Внутрішніх запитів до БД немає. Публічні результати - моделі обчислення, не HTTP DTO.

### Описова статистика

- Потрібні щонайменше два скінченні виміри та непорожня назва одиниці.
- `Mean` - арифметичне середнє.
- `SampleStandardDeviation` - sqrt(sum((x-mean)^2)/(n-1)), саме вибіркове СКО.
- `StandardError` - s/sqrt(n), не інструментальна похибка.
- Одиниця переноситься в результат; масив не змінюється.
- Відхилення обчислюються від опорного значення з центрованим зміщенням і компенсованим сумуванням квадратів. Це зменшує втрату точності для близьких значень на великому фоні.

### Довірчий інтервал

Двобічний інтервал середнього: mean ± t(n-1, 1-alpha/2)*s/sqrt(n); confidence=1-alpha, типово 0.95. Рівень довіри строго між 0 та 1.

Припущення: незалежні виміри з нормально розподіленої сукупності, невідома дисперсія. Код не доводить незалежність або нормальність даних. Для сталої серії інтервал точковий; це не доводить нульову фізичну/інструментальну похибку. Інтервал не є прогнозним інтервалом окремого нового виміру.

**Залежність:** `MathNet.Numerics` 5.0.0, ліцензія MIT, використовується лише `StudentT.InvCDF` для t-квантиля. Не реалізуємо вручну інверсію неповної бета-функції; не використовуємо табличне 1.96 для малих n. Пакет не змінює доменну модель або схему БД.

Джерело API: https://numerics.mathdotnet.com/api/MathNet.Numerics.Distributions/StudentT.htm
Статистичний метод: https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm

### Викиди

`FindOutliers` повертає вихідний індекс і значення, для яких |x-mean|/s > threshold, типово threshold=3. Використовується вибіркове s. На самій межі вимір НЕ позначається. Дані не видаляються й не перераховуються після відкидання.

Поріг можна змінити на додатне скінченне число. Для сталої вибірки позначок немає. Це евристична мітка, не доказ помилки приладу. Для n≤10 внутрішньо стандартизоване відхилення з вибірковим s не може перевищити 3: мала серія може не мати позначок навіть за очевидно різних значень. Повторне застосування після видалення викидів не реалізовано й не виконується приховано.

### Порівняння з еталоном

Абсолютне відхилення |value-reference| порівнюється з невід'ємним абсолютним допуском, включно з межею. Обидві одиниці після Trim повинні збігатися ordinal; `м` і `см` автоматично не конвертуються. Одиниці слід канонізувати при введенні даних.

Значення, еталон і допуск скінченні. Нульовий еталон та нульовий допуск допустимі. Відносний допуск, інструментальна похибка й сумарна невизначеність - інші величини, не підміняють цей контракт. Порівняння виконується для представлених double, без прихованого додавання epsilon до допуску.

### Лінійна регресія / апроксимація

Лінійна МНК-апроксимація y=a*x+b з вільним перетином; це обраний тут вид апроксимації FR-8. Поліноми вищих степенів не додаються без окремої вимоги.

- Однакова кількість скінченних x/y, щонайменше дві пари, ненульовий чисельно представний розкид x.
- `Slope` має одиницю Y/X, `Intercept` та `RootMeanSquaredResidual` - одиницю Y, R² безрозмірний.
- RMS залишків = sqrt(SSE/n), не незміщена оцінка залишкового СКО sqrt(SSE/(n-2)). Для двох точок визначається лінія, але немає оцінки залишкової дисперсії з n-2.
- R²=1-SSE/Syy, обмежено [0,1] з урахуванням округлення; для сталої y умовно R²=1, що задокументовано й тестується.
- Прогноз зберігає опорні значення та зміщення окремо. Не обчислюйте прогноз як `Slope*x+Intercept`: на великому фоні це менш стійко, ніж `Predict`.
- Екстраполяція дозволена математично, але фізична достовірність за межами навчальної вибірки не гарантується. Прогнозний інтервал і перевірка адекватності моделі не реалізовані.

## Чисельні межі та похибка

Обчислення використовують IEEE 754 double. Округлення вхідних даних до виклику відновити неможливо. Наприклад, якщо два десяткових входи вже стали однаковими double, код бачить сталу вибірку.

Переповнення проміжних результатів дає `OverflowException`, а не NaN/Infinity у результаті. Автоматичного масштабування немає: наприклад, `[0,1e160]` явно відхиляється через квадрат відхилення, хоча саме СКО представне в double. Та сама межа діє для великих розмахів регресії; поведінка закріплена тестами. Це обмеження обраного алгоритму, а не твердження, що кінцевий результат математично не існує. Повна втрата ненульової дисперсії через underflow також відхиляється; змініть масштаб одиниць. Стала x дає `ArgumentException`, а втрата її ненульового розкиду - `OverflowException`. Це явні межі поточної реалізації, а не підтримка всього математично можливого діапазону.

Для df=1 квантиль Коші обчислюється аналітично (стійко біля confidence=1); для решти - MathNet. Невдала збіжність бібліотечного квантиля перетворюється на явний `ArithmeticException` з поясненням. Не слід очікувати гарантій збіжності для довільно екстремального рівня довіри. Перевірка викидів використовує ті самі центровані відхилення, що й СКО, без повторного віднімання вже округленого середнього.

Центрування зменшує похибки віднімання великих чисел, але не дає універсальної абсолютної гарантії для довільно погано обумовленої вибірки. Базовий масштаб відносної похибки double порядку 2.22e-16; накопичення залежить від n й обумовленості. Квантилі перевірені незалежними еталонами: df=1 через аналітичний квантиль Коші та df=4 через табличне значення, з абсолютним тестовим допуском близько 1e-7. Цей допуск тестів не є обіцянкою точності на довільному вході.
