# Інтеграційна перевірка Z4 після review

Гілка: `feature/9-14-15-z4-completion`. Issues #14 та #53.
Залежності інтегровані стандартними merge: актуальний main, #49 та #47.
Це не оголошення всього проєкту готовим до здачі.

## Виправлення

- Типізований single/batch транспорт #49, максимум 50; HTTP 207 перевіряється
  разом із кількістю, порядком UUID та payload кожного результату.
- Неповна/переставлена/недостовірна відповідь не дає Sent; повтор використовує
  початковий UUID та UTC з мікросекундною точністю.
- Відомий конфлікт першої команди перевіряється перед пакетом. Пакет має
  незалежні елементи; наступні пакети серії з помилкою блокуються.
- Контекст дозволеної серії (#53): один запит, наявний фільтр доступу,
  справжні OwnerId/ManagerId і ReferenceValue; домен та міграції не змінені.
- LabManager/Administrator у клієнті мають режим читання, включно з офлайном.
  Старий профіль без Role потребує повторного входу для внесення вимірів.

## Локальні перевірки

```text
dotnet build -c Release --no-restore
Сборка успешно завершена.
    Предупреждений: 0
```

Повна збірка включає MAUI Windows та Android. Нових NuGet-залежностей немає.
Нові цільові перевірки: 28 passed, 0 failed/skipped (до додавання окремої
регресії втрати відповіді всього пакета 50). Наступний повний прогін включає її:

```text
Lab.Domain.Tests:       90 passed, 0 failed, 0 skipped
Lab.Application.Tests: 263 passed, 6 failed, 0 skipped
Lab.Postgres.Tests:     57 passed, 0 failed, 0 skipped
Python: 21 tests OK
```

Ці шість падінь — ExceptionLoggingApiTests: sandbox не може розшифрувати
наявні Windows Data Protection keys (DpapiXmlDecryptor). Вони потрапляють
у журнал тестового хоста й порушують перевірку відсутності Error.
Перенаправлення LOCALAPPDATA проблему не усунуло. Логування Windows EventLog
для локального процесу вимкнено через конфігурацію середовища, але перевірки
тестів не змінювались. Запитано повний повтор поза sandbox; його результат
не заявляється, доки журнал не прочитано. Новий CI має перевірити весь head.

PostgreSQL 15: окремий стек `sigma-z4-completion`, порт 55435,
тестова база `sigma_z4_tests_20261102`; секрети поза репозиторієм.
ManagerContextIntegrationTests виконує API→SQLite з обома провайдерами,
перевіряє власність/еталон, офлайн-відновлення, заборону мутацій,
відкликання призначення, 401/404 та OpenAPI.
ClientApiIntegrationTests перевіряє втрату single-відповіді та всього
50-item пакета на PostgreSQL, повтор без дублювання й точність UTC.

## Межі приймання

- Контракт #53 потребує незалежного review власників Z2/Z3.
- Відомі серверні зауваження #49 (узгоджена версія дубля та ізоляція помилки
  читання Version всередині catch) не виправлялися у чужій гілці й не скасовані.
- Нового повного runtime UI-сценарію Android/Windows через довірений HTTPS
  під час цього review не виконано. Компіляція й TestServer не замінюють його.
- #14 не закривається до зеленого фінального CI, серверних виправлень і
  завершення незалежного приймання. Попередній звіт від 30.10 лишається історичним.
